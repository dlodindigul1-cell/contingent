## 1. Neon
Neon-ல் புதிய project -> Connection string (`postgresql://...sslmode=require`) நகலெடுக்கவும்.

## 2. உள்ளூரில் இயக்குதல்
```
pip install -r requirements.txt
export DATABASE_URL="<Neon connection string>"
export ADMIN_PASSWORD="<உங்கள் கடவுச்சொல்>"
python app.py          # http://localhost:5000
```

## 3. Google Sheet தரவு இறக்கம் — Admin வழியாக CSV Upload
1. முகப்பில் **Admin** -> கடவுச்சொல் -> **📥 தரவு இறக்கம் — CSV Upload** (அல்லது நேரடியாக `/admin/import`).
2. முதல் முறை மட்டும் **Database அட்டவணைகளை உருவாக்கு** பொத்தானை அழுத்தவும்.
3. ஒவ்வொரு Google Sheet-ஐயும் File > Download > CSV ஆக இறக்கி, அந்தந்த வரிசையில் தேர்ந்தெடுத்து **ஏற்று** அழுத்தவும்
   (அல்லது எல்லாவற்றையும் தேர்ந்தெடுத்து **அனைத்தையும் வரிசையாக ஏற்று**):
   நூலகப் பட்டியல் -> நாளிதழ் பட்டியல் -> நூலகம்-நாளிதழ் இணைப்பு -> விடுமுறை -> விடுப்பு -> வாடகை -> தினக்கூலி -> பழைய contingent.
4. மீண்டும் upload செய்தால் புதுப்பிக்கும் (நகல் உருவாகாது). தவிர்க்கப்பட்ட வரிகள் திரையிலேயே காட்டப்படும்.

(விருப்பம்: `python import_data.py libraries Sheet1.csv` போன்ற command line முறையும் அதே logic-ஐப் பயன்படுத்தும்.)

## 4. Render
GitHub-ல் இந்த repo-வை push செய்து, Render-ல் "New > Blueprint" தேர்ந்தெடுக்கவும் (`render.yaml`).
Environment variables: `DATABASE_URL`, `ADMIN_PASSWORD` (`SECRET_KEY` தானாக உருவாகும்).

## நூலக மேலாண்மை (புதியது)
- நூலகப் பட்டியல் Excel-ல் இப்போது **E நெடுவரிசை = ஊதிய மையம்** (A பெயர், B குறியீடு, C மின்னஞ்சல், D வகை).
- **மாதிரி Excel பதிவிறக்கம்** இனி ஏற்கனவே பதிவு செய்த தரவுடன் வரும் (நூலகங்கள், விடுமுறை, விடுப்பு, தினக்கூலி அனுமதி); பதிவு இல்லையெனில் மட்டும் மாதிரி வரி.
- Admin மெனு **11. நூலகம் · வகை · ஊதிய மையம்**: நூலகங்களைச் சேர்க்க / திருத்த / நீக்க; நூலக வகைகள், ஊதிய மையங்களைச் சேர்க்க / பெயர் மாற்ற / நீக்க.
  வகை அல்லது ஊதிய மையம் பெயர் மாற்றினால் அந்த நூலகங்கள் அனைத்திலும் மாறும்; பயன்பாட்டில் உள்ளதை நீக்க முடியாது.
- புதிய நெடுவரிசை / அட்டவணைகள் `schema.sql` மூலம் முதல் request-ல் தானாக உருவாகும்.

மேலே வலப்புறம் **🚪 வெளியேறு** மூலம் பயனரை மாற்றலாம்.

## தினக்கூலி தொகை சேமிப்பு & புதிய Excel வடிவம்
- நூலகர் பதிவு செய்யும் போது **பெயர் / பணிநாட்கள்** சில்லறை செலவினப் பதிவுக்காக மட்டுமே; பதிவின் நேரத்தில் **நாட்கள் × கூலி விகிதம் = தொகை** கணக்கிடப்பட்டு `partner_amount`, `staff_amount`, `part_time_amount` ஆக நிலையாகச் சேமிக்கப்படும் (பின்னர் விகிதம் மாறினாலும் மாறாது).
- மொத்தக் கணக்கு, அனுமதித் தொகை, Excel ஏற்றம் எல்லாம் இந்தத் தொகைகளையே பயன்படுத்தும். schema புதுப்பிப்புக்கு முந்தைய பதிவுகளுக்கு (நாட்கள் மட்டும் உள்ளவை) ஒருமுறை தற்போதைய விகிதத்தில் தொகை நிரப்பப்படும்.
- **முந்தைய மாதங்கள் (Excel)** இப்போது தொகை மட்டும் உள்ள வடிவம்: மாதம், ஊதிய மையம், நூலகத்தின் பெயர், நாளிதழ்கள், வாடகை, மின் கட்டணம், தினக்கூலி 4, செலவினங்கள், மொத்தங்கள் (சூத்திரம்). பழைய நீண்ட வடிவ Excel-ம் தொடர்ந்து ஏற்கப்படும்.

## அறிக்கைகள் (Admin மெனு — புதிய குழு)
- **12. ஊதிய மைய நூலகர் அறிக்கை:** ஊதிய மையம் + மாதம் -> வ.எண். | நூலகத்தின் பெயர் | மொத்தத் தொகை (அனுமதித் தொகை − நாளிதழ் − வாடகை). வரிசை: மாவட்ட மைய நூலகம் -> முழு நேர கிளை -> கிளை -> ஊர்ப்புற -> பகுதி நேரம் (ஒரே வகைக்குள் நூலகப் பட்டியல் வரிசை). கடைசியில் மொத்தம் எண்ணிலும் ஆங்கில வார்த்தைகளிலும் (`amount_in_words`).
