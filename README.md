# நூலக Contingent / வரவினங்கள் — Flask + Neon + Render (கட்டம் 1)

## உள்ளவை (கட்டம் 1)
நூலகத் தேர்வு + மின்னஞ்சல், contingent படிவம் (சேமி/புதுப்பி/ஏற்கனவே உள்ளதை ஏற்று),
நாளிதழ் Active பட்டியல் + Admin, பணி நாட்கள், வாடகை, தினக்கூலி அனுமதி.

## பின்னர் வருபவை
கட்டம் 2: வரவினங்கள் + UTR/வங்கி சரிபார்ப்பு  ·  கட்டம் 3: PDF, மெயில், ஆண்டு abstract
(இப்போது இவற்றின் பொத்தான்கள் "அடுத்த கட்டத்தில் வரும்" என்ற செய்தி காட்டும்)

## 1. Neon
Neon-ல் புதிய project -> Connection string (`postgresql://...sslmode=require`) நகலெடுக்கவும்.

## 2. உள்ளூரில் இயக்குதல்
```
pip install -r requirements.txt
export DATABASE_URL="<Neon connection string>"
export ADMIN_PASSWORD="<உங்கள் கடவுச்சொல்>"
python app.py          # http://localhost:5000
```

## 3. Google Sheet தரவு இறக்கம் — Admin வழியாக CSV Upload
1. முகப்பில் **Admin** -> கடவுச்சொல் -> **📥 தரவு இறக்கம் — CSV Upload** (அல்லது நேரடியாக `/admin/import`).
2. முதல் முறை மட்டும் **Database அட்டவணைகளை உருவாக்கு** பொத்தானை அழுத்தவும்.
3. ஒவ்வொரு Google Sheet-ஐயும் File > Download > CSV ஆக இறக்கி, அந்தந்த வரிசையில் தேர்ந்தெடுத்து **ஏற்று** அழுத்தவும்
   (அல்லது எல்லாவற்றையும் தேர்ந்தெடுத்து **அனைத்தையும் வரிசையாக ஏற்று**):
   நூலகப் பட்டியல் -> நாளிதழ் பட்டியல் -> நூலகம்-நாளிதழ் இணைப்பு -> விடுமுறை -> விடுப்பு -> வாடகை -> தினக்கூலி -> பழைய contingent.
4. மீண்டும் upload செய்தால் புதுப்பிக்கும் (நகல் உருவாகாது). தவிர்க்கப்பட்ட வரிகள் திரையிலேயே காட்டப்படும்.

(விருப்பம்: `python import_data.py libraries Sheet1.csv` போன்ற command line முறையும் அதே logic-ஐப் பயன்படுத்தும்.)

## 4. Render
GitHub-ல் இந்த repo-வை push செய்து, Render-ல் "New > Blueprint" தேர்ந்தெடுக்கவும் (`render.yaml`).
Environment variables: `DATABASE_URL`, `ADMIN_PASSWORD` (`SECRET_KEY` தானாக உருவாகும்).

## உள்நுழைவு
முகப்பில் இரண்டு தேர்வுகள்: **நூலகர்** (கடவுச்சொல் இல்லை) மற்றும் **Admin** (கடவுச்சொல் தேவை).
Admin கடவுச்சொல் Render-ன் `ADMIN_PASSWORD` environment variable-ல் இருந்து எடுக்கப்படும்
(அமைக்காவிட்டால் code-ல் உள்ள இயல்புநிலை கடவுச்சொல்). Admin: புதிய நிர்வாகப் பக்கம் `/admin` (நூலகங்கள் CSV ஏற்றம், நாளிதழ் மேலாண்மை உள்ளிட்டவை).
மேலே வலப்புறம் **🚪 வெளியேறு** மூலம் பயனரை மாற்றலாம்.
